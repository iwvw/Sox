<h1 align="center">Sox</h1>

<p align="center">Windows 文件搜索工具。</p>

按 `Alt+Space` 呼出搜索框全盘秒搜；在「打开 / 保存」对话框里也会弹出搜索面板，选中即跳转，按 `Ctrl+G` 跳回最近浏览的目录。

到 [Releases](https://github.com/iwvw/Sox/releases) 下载安装包即可，合并版自带运行时。

## 参考

- [Lertaro](https://github.com/Lertaro/Lertaro) — 后端索引与搜索核心（基于其 MIT 快照改写）
- [PowerToys](https://github.com/microsoft/PowerToys) — CmdPal 的材质与界面架构参考
