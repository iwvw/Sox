# ADR-0003. 拼音索引：首字母 + 全拼前缀

日期：2026-09-29
状态：Accepted

## 背景

用户使用中文，需要输入 `wxg` 命中「微信」这类拼音缩写匹配。这是中文搜索工具的必要体验。

## 决策

- 为中文文件名生成两路拼音索引：
  - 首字母串（「微信.exe」→ `wx.exe`）
  - 全拼前缀（「微信.exe」→ `weixin.exe`）
- 拼音生成封装在 `Sox.Core/Pinyin`，底层用 NuGet 拼音库，接口可替换
- 查询时拼音索引与 Trie 前缀索引结果合并，再做多词交集

## 后果

- 内存 +10MB 预算；索引写入时多一步拼音生成
- 不做完整全拼子串索引（省内存，拼音长词子串走线性扫兜底）
- 排序语义中拼音命中相关度记 0.6（低于前缀精确 1.0 / 前缀模糊 0.9）
