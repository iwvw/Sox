# ADR-0005. 查询实时化：防抖 + 取消 + 后台线程 + top30

日期：2026-09-29
状态：Accepted

## 背景

要求「跟随输入实时显示结果」，且中文输入法有组词组合态，需要跟手且不卡 UI。

## 决策

- 输入变化 → 防抖 40-80ms → 发起查询，`CancellationToken` 取消上一次未完成查询（防竞态）
- 查询在后台线程执行（200 万条扫描 5-10ms 不占 UI），结果经 `ObservableCollection` 替换回绑
- IME 组合期（拼音未上屏）不触发查询，以 `TextComposition` 事件判断
- 排序引擎只回 top30，XAML 用 `VirtualizingStackPanel` 只渲染可见项
- 空输入显示「最近 / 收藏 / 常用目录」（排序引擎冷启动态）

## 后果

- 输入跟手无卡顿，中文输入不跳动
- 复杂度集中在 SearchViewModel（防抖 + 取消 + 线程切换），其余层无感
- 查询延迟预算：防抖 80ms + 扫描 10ms + 排序 5ms + 渲染 16ms，总 < 120ms
