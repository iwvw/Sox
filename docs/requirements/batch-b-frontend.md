## 需求清单

### R1. 呼出跟随鼠标所在显示器
- 呼出时按鼠标所在显示器定位并居中（`MonitorFromPoint(GetCursorPos)`）。
- 保留"记住上次显示器"作为可选策略（后续设置项）。

### R2. 交互优化（键盘左右键 + 动作菜单）
- 结果列表：`←` 直接打开当前选中项；`→` 打开该项的动作菜单。
- 动作菜单**替换**结果列表区域显示（不是弹出 Flyout）。
- 菜单内：`←` 返回结果列表；`↑↓` 选择；`Enter` 执行。
- 菜单功能尽量全面：打开、打开所在文件夹、以管理员运行、复制路径、复制文件名、重命名、删除到回收站、属性、固定到收藏、相关设置等（按结果类型/文件存在性裁剪）。

### R3. 文件预览面板（右侧合并）
- 主卡片右侧新增预览列，与结果列表同一卡片、同一材质。
- 图片：png/jpg/jpeg/gif/webp/bmp/tiff/ico/svg（SVG 用 Win2D 或 SvgImageSource）。
- 文本/代码：语法高亮（自研轻量高亮，避免引入大依赖）。
- 无可用预览时整个预览列隐藏，主窗口回到纯列表宽度。
- 预览加载在后台线程，避免阻塞 UI。

### R4. 搜索性能（最高优先级）
- **真流式上屏**：不等三路源全部完成，`onResult` 增量推送 + 节流刷新（~40ms）。
- **图标异步**：`ResultItem` 构造不再同步跑 Shell 图标；后台加载后 `PropertyChanged` 更新。
- **增量排序**：已有结果先排序上屏，后续结果到达合并重排（限制条数）。
- 目标：输入时首屏 < 100ms 出结果；不出现输入卡顿。

### R5. 设置面板（WinUI 3）
- 独立窗口，`SettingsCard`/`SettingsExpander` 分组（参考 WSLCC `SettingsPage.xaml`）。
- 分组：外观（主题/材质/透明度）、搜索（模糊/排除目录/结果数）、热键、索引管理、历史/收藏、关于。
- 读写 `UserSettings`（前端直接读写用户设置文件；机器设置经 pipe）。
- 内存/存储：按需创建窗口、关闭即释放；发布配置参考 momomi/WSLCC 的裁剪。

### R6. 托盘 + 主题化右键菜单
- WinForms `NotifyIcon` + `ContextMenuStrip`（参考 momomi/WSLCC）。
- 菜单项：设置、关于/检查更新、退出。
- 菜单跟随系统深浅色主题化。
- 左键单击托盘：呼出搜索框。
- 遵循 `UserSettings.HideTrayIcon`。

## 执行顺序（按依赖）

1. R4 搜索性能（独立、最高优先、可改 Core）
2. R1 多显示器呼出（独立、小）
3. R2 交互（左右键 + 动作菜单）
4. R3 预览面板（依赖布局）
5. R6 托盘 + 菜单（设置入口的前提）
6. R5 设置面板（依赖托盘入口）
